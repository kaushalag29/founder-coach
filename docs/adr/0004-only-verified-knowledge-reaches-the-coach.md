# Only Verified knowledge is indexed and reaches the coach

Advice or Takeaways whose Evidence was not found in the Document text are kept in the JSON
record but never indexed, returned by a tool or cited. The alternative — indexing
everything with a confidence score — lets the host model cite a famous quote the speaker
never said (observed in testing), which is the one failure a founder-coach cannot afford.

## Consequences

Coverage drops by the unverified share (~4-15% per Talk so far); improving extraction,
not loosening verification, is how coverage grows.
